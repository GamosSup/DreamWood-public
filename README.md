# Dreamwood — открытая часть приложения

Этот репозиторий содержит только проверенный код приложения. Данные сотрудников, рабочие таблицы, файлы афиши, резервные копии и история прежнего репозитория здесь не хранятся.

Данные приложения остаются в базе с проверкой прав. Приватные рабочие материалы и миграции хранятся отдельно. Файл афиши можно загрузить через интерфейс руководителя.

Для проверки сборки: `node tools/build-public.cjs`. Результат находится в `safe-public/`; серверные функции находятся в `functions/`.

Изменения в `main` проверяются и публикуются через GitHub Actions в Cloudflare Pages.

Перед каждым изменением проверяйте файлы и их содержимое на персональные данные и секреты. `.gitignore` помогает исключить известные закрытые пути, но сам по себе не гарантирует конфиденциальность.
